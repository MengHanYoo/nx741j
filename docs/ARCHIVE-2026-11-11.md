## 1. 第 1 层：镜像格式与启动路径的确定（11-05 → 11-07）

| 步骤 | 结论 |
|---|---|
| 对比解锁镜像 `uefi_unlock_8e.img` | boot 分区 kernel 必须是 **gzip(shim+FV)**；**不能追加 DT**；boot 内 **ramdisk=0**（GKI 约定） |
| FD 基址核对 | 解锁镜像 shim 头 `FD_BASE=0xFF300000`、`FD_SIZE=0x400000`；我们此前用的 `0xC6900000`（抄 infiniti）是错的 |
| 结果 | 修正后镜像可被 ABL 接受（不再回落 fastboot），但显示花屏/重启 → 说明固件在跑、显示路径未通 |
| 最终路线 | 放弃 boot_a 注入，改 **efisp**：`gbl_superfastboot` 证明 efisp 的 PE 一定被执行；自研 loader `p5.c` 实机成功，屏幕出 DXE 日志 |

## 4. 第 6 层：UFS 存储（11-10 → 11-11，当前唯一阻塞）

| 步骤 | 结果 |
|---|---|
| 控制器接管 | probe=3 成功：停止固件队列、安装请求列表（`ba=c3aff000` 回读一致）、SMMU 报告 bypass |
| 首条命令 | **probe=4（TEST UNIT READY）门铃后挂死**：CPU 不返回，连 panic 都打不出来 → 指向描述符 DMA 取指 |
| SMMU | IDR0=`0x4c017e7a`（122 组）、IDR1=`0x50000051`（81 bank，64 页 CB）、IDR2=`0x5211`；`SCTLR.M=0` 全局 bypass；IDR1 bit29 读回置位导致几何被拒，本地 override 掩掉该位 |
| 厂商驱动反汇编 | `ufshcd_make_hba_operational`：多写 **0x4c 厂商寄存器**、初始化 **UTMRL（0x70/0x74/0x80）**、IE=`0x700a85`、门铃按 **MCQ** 路径写 SQ doorbell |
