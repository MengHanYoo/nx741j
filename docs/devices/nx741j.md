# Nubia Z80 Ultra (NX741J)

[Device repository](https://github.com/UniXNU/UniXNU-nx741j),
[porting steps](/porting/steps),
[firmware](https://github.com/MengHanYoo/uefi-nx741j).

The device repository owns board drivers, hardware configuration and the
porting record. Use the [record guide](/porting/records) with the sections below.

Target: Qualcomm SM8850 (Kaanapali / canoe), iOS 16.7.16 (20H392), XNU 8796.141.3,
arm64, 4 KiB pages. The current boot path uses a self-built EFI loader in the
`efisp` partition that reads the payload and the firmware volume from `rawdump`.
