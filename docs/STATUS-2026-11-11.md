# STATUS 2026-11-11 — storage bring-up, SMMU, and the model gate

Living record of what was analysed, what was done, what is broken, and what is next.
Everything here follows the UniXNU project inputs (board.toml, components.toml,
patches/xnu/series, official docs); external projects are reference only.

## 3. SMMU findings (Qianfeng apps-smmu @0x15000000, SID 0x60)

* IDR0=0x4c017e7a (122 stream groups), IDR1=0x50000051 (81 banks, 64-page CB array),
  IDR2=0x5211 (AArch64 stage 1 supported).
* IDR1 bit 29 reads back set while the block settles; a set bit makes the page
  exponent 7 (128 pages) and the driver rejects the geometry ("geometry window").
  The local ShengUfs override masks bit 29 and retries the plan.
* SCTLR.M is 0, i.e. the SMMU is globally bypassed, so UFS DMA is physical. The
  driver now skips context-bank programming entirely in that state and reports
  bypass; programming a CB offset this QEMU does not implement aborted the bus.

## 4. UFS state

* Controller 0x1d84000: cap=d5c7031f, ver=00000400, hcs=0000010f, hce=00000001.
* probe=3 succeeds: firmware queue stopped, our request list installed
  (ba=c3aff000 read back), SMMU bypass reported.
* probe=4 (TEST UNIT READY LUN0) stalls after the doorbell: the CPU never returns
  from the following MMIO read, so no panic can be printed. This points at the
  DMA fetch of the request descriptor, not at the command itself.

## 6. Model gate (scripts/build-and-test.sh)

Every build now runs, in this order: kernel -> payload -> firmware ->
**official smoke suite (package/Scripts/smoke.sh, six scenarios)** -> QEMU with the
real payload, the generated fixture ADT, no-video=1 and -d int, printing
"MODEL kernel stopped at ...". The gate fails if a marker is missing, if the
serial log has no guest firmware banner, or if the smoke suite fails.

## 7. Open problems

1. **UFS first command stalls the bus.** Next: reuse the firmware's own request
   list (do not replace UTRLBA) and ring the doorbell against it; if that still
   stalls, verify the reference clock / link state before the doorbell.
2. **Prelink holes.** IOCryptoAcceleratorFamily's __TEXT_EXEC extent is declared
   in the report but the constructor bytes are zero in kernel.macho.
3. **Reproducibility.** status reports two local sources not pinned by
   unixnu.lock (ShengUfs override and the sm8850 feed).
4. **Display in the kernel.** GopFramebuffer is selected but not in
   [kernel] archives; the kernel has no display driver yet.
5. **Input.** The panel is a Synaptics TCM (SPI19 @1a80000); the catalog reference
   implementation is Novatek, so a TCM driver has to be written.
