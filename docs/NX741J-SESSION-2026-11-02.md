## 4. 回 Android 后无限重启的根因与解决（2026-11-02 13:30）

现象：刷 METAL 镜像跑完 iOS 后，把 `E:\Nubia_Flash_Brick\备份\ZTEToolBoxParBak_2026.10.24_22.38.43.421\images\boot_a.img` 刷回 `boot_a`，手机无限重启。

**根因：那份 boot_a 和手机当前系统不是同一版。**

| 来源 | boot 头里的 kernel_size（offset 8） | sha256 |
|---|---|---|
| 10/24 备份 `boot_a.img` | 59,481,? | `3d988255d51fdaf7d6ae46fc3a36373d37e88bf52e8b437557d12b0148a90cf7` |
| 手机当前系统（`Xiaomi/nezha CP2A.260605.016 / OS4.0.0.10.XPACNXM`） | **59,512,128** | —（未备份） |

boot / vendor_boot / system / vbmeta 是一整套，单独换 boot 会校验或挂载失败 → bootloop。10/24 那份能恢复，是因为当时手机还是旧版系统；中间换过 ROM 后就失效了。

**解决方案（已落地成脚本，位于工作区 `z80u-collect\`）**：

1. `dump_boot.ps1`：Android 下把**当前** `boot_a` / `init_boot_a` / `vendor_boot_a` 原样 `dd` 到 `z80u-collect\stock\`，文件名带时间戳，并打印 sha256；
2. `restore_android.ps1`：改成**只认 `stock\boot_a_*.img` 里最新的那份**，没有就报 `NO_CURRENT_BOOT_DUMP` 退出，**绝不**回退到 10/24 旧镜像；
3. 标准流程：换 ROM 后先跑 `dump_boot.ps1` → 刷 METAL → 跑 iOS → 进 fastboot → `restore_android.ps1`。

**注意**：每次换 ROM（或 OTA）都要重新 dump 一次；旧的 boot 备份只对当时的系统有效。

## 6. 今晚（回家后）排队的实验：抓 assetsd 的 NSAssert 原文

镜像里已经带上了补丁 05：`com.apple.assetsd.plist` 增加 `StandardErrorPath=/dev/console`、`StandardOutPath=/dev/console`（1174 → 1202 B，已随 `iosroot-BUILD.img` 推到手机，17 GB / 316.4 s / exit 0）。abort 前 libc++abi/Foundation 打印的 `*** Terminating app due to uncaught exception ...` 会经 stderr 落到内核控制台，进 `ioslog.img`。

操作步骤：

1. 手机在 Android 下，确认 `boot_a` 是原版（`stock\boot_a_20261102-1335.img` 已备份，sha256 `3d988255…`）；
2. 刷 `METAL55-boot_a.img`（sha256 `77d1989d…`）到 `boot_a` 并重启；
3. iOS 跑 **2–3 分钟**（assetsd 很早就起，不必等桌面完全就绪）；
4. 回 Android：关机后音量下 + 电源进 fastboot → `restore_android.ps1`；进不去就用 9008 + 工具箱；
5. 拉日志：`python z80u-collect\_log54.py`，然后搜 `|assetsd|`、`Terminating app due to uncaught exception`、`NSInternalInconsistency`。

期望拿到：抛出点 `PLLibraryServicesOperation` 里的具体断言文本（例如“库缺失/路径不可写/沙盒拒绝”），据此决定下一步是预置照片库、修沙盒，还是需要安装 HEIC 解码相关组件。

**规则（从今天起）**：任何镜像改动都进 `image/manifest.json` + `z80u-collect/image-artifacts/`，用 `build_image.ps1` 从 `iosroot-GOLDEN.img` 重建并校验，**不再手工改成品镜像**；重建产物 `iosroot-BUILD.img` 与旧 SEAL 已逐文件一致（331,635 条目，0 差异）。
