### 二、当前阻塞（精确到代码）

`IOStorageFamily` 的 `IOBlockStorageDriver::instantiateMediaObject()` 用写死的 `""` 作为 IOMedia 的
content hint；这个 kext 来自预链接 kernelcache，驱动侧无法在创建时设置，发布后再改也无效：

- 发布后内核进入单线程根设备等待，新建线程不被调度（`tag thread start=0` 但无 enter）；
- 在 `NativeUfs::start()` 里查注册表会因 IOKit 匹配锁而死锁；
- `IOMedia::metaClass` 不在内核符号里，无法链接自建子类。

### 三、已做到哪一步

- `/opt/work/iostorage-src`：`refer/IOStorageFamily` 副本，`instantiateMediaObject` 改为读
  provider 的 `kIOMediaContentHintKey`（缺省 `""`），另有 `NXUFS storage` 标记日志；
- `<tree>/build/iostorage/libIOStorageFamily.a` 已生成（含 IOMedia / IOBlockStorageDriver / IOBlockStorageDevice），`strings` 可见标记；
- `scripts/build-xnu-4k-baseline.sh` 已加 force-load 分支（`$ROOT/build/iostorage/libIOStorageFamily.a`）；
- 但 `./unixnu kernel` 复用缓存，未真正重链接，内核中无标记。

### 四、下一步（按顺序）

## English

### Done (reproducible)

Boot chain stages 1-5 pass; the adopted firmware queue reads the SHNGROOT manifest at fixed LBA
246,662,139; the signed-root gates are bypassed at run time with `native-ufs-noverify=1`; and the
official stage-6 condition "publish OS and SystemOS" is met — `publication done=1 published=2`.
Build-side source override `UNIXNU_UFS_SOURCE` keeps the patched driver in the object file.

### Blocker

`IOBlockStorageDriver::instantiateMediaObject()` in the prelinked IOStorageFamily initialises
media with a hard-coded empty content hint, so APFS never matches the published windows. Tagging
after publication cannot work (post-start threads are not scheduled; registry queries inside
`start()` deadlock) and `IOMedia` cannot be subclassed at link time.

### Progress on the fix

`/opt/work/iostorage-src` holds a patched copy (hint from `kIOMediaContentHintKey`, plus an
`NXUFS storage` marker); `<tree>/build/iostorage/libIOStorageFamily.a` builds and contains the
marker; `scripts/build-xnu-4k-baseline.sh` has the force-load branch. The kernel link still skips
the archive because `./unixnu kernel` reuses cached objects.

### Next

Force a real kernel relink; confirm `LD_KERNEL_ARCHIVES` carries the archive (`OWN-STORAGE-DEBUG`);
exclude `com.apple.iokit.IOStorageFamily` from the prelink closure; build, pass the QEMU gate,
flash once; read the APFS volume UUID from the log; fill `[payload.adt] root_match_volume_uuid`;
verify root mount and `launchd`.
